# Napplet agent skills

This template does not vendor independent skill bodies. Install the current
official guidance when an agent will work on the project:

```bash
npx @napplet/skills install --to codex
```

Use the installed `make-napplet`, `design-napplet`, `build-napplet`, and
`test-napplet` workflows. Living NIP-5D and NAP documents remain protocol truth.
